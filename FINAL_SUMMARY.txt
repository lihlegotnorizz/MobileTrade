🚀 QUICK START (Choose one method)

METHOD 1: Automated Setup (RECOMMENDED)
  Windows:
    1. Double-click: MobileTrade\setup.bat
    2. Follow prompts
    3. Backend: cd backend && npm run dev
    4. Frontend: cd frontend && python -m http.server 3000

  Mac/Linux:
    1. bash MobileTrade/setup.sh
    2. Backend: cd backend && npm run dev
    3. Frontend: cd frontend && python -m http.server 3000

METHOD 2: Manual Setup
  1. npm install (in backend folder)
  2. Copy .env.example to .env
  3. Update environment variables
  4. npm run dev (backend)
  5. python -m http.server 3000 (frontend)

ACCESS POINTS:
  Frontend:  http://localhost:3000
  Backend:   http://localhost:5000
  API Docs:  http://localhost:5000/api/health

🆘 TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════════

Issue: "Cannot connect to MongoDB"
Solution: Start MongoDB or use MongoDB Atlas connection string

Issue: "Port 5000 already in use"
Solution: Change PORT in .env or kill process using that port

Issue: "CORS error in browser console"
Solution: Verify frontend (localhost:3000) and backend (localhost:5000) are correct

Issue: "401 Unauthorized on protected endpoints"
Solution: Ensure you're sending valid JWT token in Authorization header

Issue: "ModuleNotFoundError: No module named http.server"
Solution: Use: python3 -m http.server 3000
